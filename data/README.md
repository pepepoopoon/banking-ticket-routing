# Данные

Ожидается UTF-8 CSV со столбцами `ticket_id`, `text`, `intent`. ID и текст уникальны,
а каждый intent должен содержать не менее восьми примеров для стратифицированного
train/validation/test split и внутренней калибровки.

`smoke.csv` — детерминированный набор полностью вымышленных английских обращений. Он
проверяет код, но не воспроизводит распределение BANKING77.

Официальный источник: [PolyAI BANKING77](https://github.com/PolyAI-LDN/task-specific-datasets/tree/master/banking_data),
13 083 обращения, 77 intent-классов. Лицензия — [CC BY
4.0](https://creativecommons.org/licenses/by/4.0/); при использовании требуется
атрибуция. Оригинальные данные не включены и не загружаются автоматически. Сохраняйте
официальный test split отдельно от обучения; текущий CSV-интерфейс предназначен для
самостоятельно подготовленного корпуса или smoke-проверки.
